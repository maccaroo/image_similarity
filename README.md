# Use RAG to find similar images based on semantic content.

## Create Python environment

Checkout this code to a new folder. Open a terminal in the folder and run the following commands:

Setup the environment

```bash
python -m venv .venv && source .venv/bin/activate

pip install --upgrade pip
pip install -r requirements.txt
```

## Run code

The main code implementation is here: [image_similarity.py](./image_similarity.py).

To run it, you can use this notebook: [image_similarity.ipynb](./image_similarity.ipynb).
